# Как залить конструктор в интернет и генерировать ссылки

## Пошаговая инструкция

---

## Часть 1: GitHub Pages (хостинг конструктора)

### Шаг 1. Создайте аккаунт на GitHub
- Зайдите на https://github.com
- Зарегистрируйтесь (бесплатно)

### Шаг 2. Создайте репозиторий
- Нажмите **"+"** → **"New repository"**
- Название: `love-constructor` (или любое)
- Выберите **Public**
- Нажмите **"Create repository"**

### Шаг 3. Залейте файлы
**Вариант А — через веб (простой):**
- В репозитории нажмите **"Add file" → "Upload files"**
- Перетащите ВСЕ файлы из папки проекта:
  - `index.html`
  - `view.html`
  - `css/` (папку)
  - `js/` (папку)
- Нажмите **"Commit changes"**

**Вариант Б — через терминал (если есть git):**
```bash
cd путь/к/папке/конструктора
git remote add origin https://github.com/ВАШ_НИКНЕЙМ/love-constructor.git
git push -u origin master
```

### Шаг 4. Включите GitHub Pages
- В репозитории: **Settings** → **Pages** (левое меню)
- Source: выберите **"Deploy from a branch"**
- Branch: **master** / **(root)**
- Нажмите **Save**
- Подождите 1-2 минуты
- Ваш сайт будет доступен по адресу:
  `https://ВАШ_НИКНЕЙМ.github.io/love-constructor/`

## Часть 2: Firebase (хранение приглашений)

### Шаг 1. Создайте проект Firebase
- Зайдите на https://console.firebase.google.com
- Войдите через Google-аккаунт
- Нажмите **"Создать проект"**
- Название: `love-constructor` (или любое)
- Нажмите **"Создать проект"**

### Шаг 2. Создайте базу данных
- В консоли Firebase: **Build** → **Realtime Database**
- Нажмите **"Создать базу данных"**
- Выберите **любой регион**
- **Важно:** выберите **"Режим тестирования"** (открытый доступ)
- Нажмите **"Готово"**

### Шаг 3. Скопируйте URL базы данных
- На странице Realtime Database вы увидите URL вида:
  `https://love-constructor-xxxxx-default-rtdb.firebaseio.com`
- **Скопируйте его**

### Шаг 4. Установите правила доступа
- На вкладке **Realtime Database** → **Правила**
- Вставьте:
```json
{
  "rules": {
    "invitations": {
      ".read": true,
      ".write": true
    },
    "responses": {
      ".read": true,
      ".write": true
    }
  }
}
```
- Нажмите **"Опубликовать"**

---

## Часть 3: Соединяем всё вместе

### Шаг 1. Вставьте URL Firebase в код
- Откройте файл `js/export.js`
- Найдите строку:
  ```javascript
  FIREBASE_URL: 'https://ВАШ-ПРОЕКТ-default-rtdb.firebaseio.com',
  ```
- Замените `ВАШ-ПРОЕКТ` на ваш реальный URL из Firebase
- Сохраните файл

### Шаг 2. Обновите view.html
- Откройте файл `view.html`
- Найдите строку:
  ```javascript
  const FIREBASE_URL = 'https://ВАШ-ПРОЕКТ-default-rtdb.firebaseio.com';
  ```
- Замените на тот же URL
- Сохраните файл

### Шаг 3. Залейте обновлённые файлы на GitHub
- Повторите Шаг 3 из Части 1 (загрузите изменённые файлы)

---

## Часть 4: Пользование!

1. Откройте `https://ВАШ_НИКНЕЙМ.github.io/love-constructor/`
2. Создайте приглашение в конструкторе
3. Нажмите **"Опубликовать"** в верхней панели
4. Получите ссылку вида:
   `https://ВАШ_НИКНЕЙМ.github.io/love-constructor/view.html?id=AbCdEfGh`
5. Отправьте ссылку девушке
6. Она откроет её и увидит красивое приглашение!

## FAQ

**В: Это бесплатно?**
О: Да! GitHub Pages и Firebase бесплатный тариф полностью бесплатны.

**В: Сколько приглашений можно создать?**
О: На бесплатном тарифе Firebase — до 1 ГБ данных. Это тысячи приглашений.

**В: Фото и музыка сохраняются?**
О: Да, они сохраняются как base64 прямо в базу данных. Но для больших файлов лучше использовать внешние хостинги изображений.

**В: Как удалить приглашение?**
О: В консоли Firebase → Realtime Database → найдите нужную запись и удалите её.

**В: Ссылка безопасна?**
О: Кто угодно может открыть приглашение по ссылке. Если нужно ограничить доступ — настройте правила Firebase.
